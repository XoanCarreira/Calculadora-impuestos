# Calculador Impuestos

## Descripción
Aplicacion web que calcula el total a pagar con una tasa del 21% sobre una cantidad introducida por el usuario.


## Requisitos
- Git (version 2.43 ou superior)


## Instalación
Clonar desde GitHub


```bash
git clone https://github.com/XoanCarreira/Calculadora-impuestos.git

```

## Uso
Una vez instalada, se puede visualizar abriendo el archivo index.html con cualquiera de los principales navegadores modernos.
